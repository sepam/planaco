Which task is making you late?

The same plan, in code.

The plan above as a Python script, a YAML file for the command line, or a prompt for a coding agent.

Python

from planaco import Task, Project

project = Project(name="Web App", unit="days")

design   = Task(name="Design",   min_duration=5,  mode_duration=7,  max_duration=14)
frontend = Task(name="Frontend", min_duration=8,  mode_duration=12, max_duration=15)
backend  = Task(name="Backend",  min_duration=10, mode_duration=15, max_duration=25)
testing  = Task(name="Testing",  min_duration=2,  mode_duration=3,  max_duration=5)

project.add_task(design)
project.add_task(frontend, depends_on=[design])
project.add_task(backend,  depends_on=[design])
project.add_task(testing,  depends_on=[frontend, backend])

stats = project.statistics(n=10_000)
print(stats["percentiles"]["p85"])

Output

Real output from version 0.3.1. Both runs are seeded with 42, so they reproduce; each task_id is new on every run. The chart on this page runs a JavaScript port of the same model with its own random numbers, so its figures differ slightly: Frontend is on the critical path in 5.9% of its runs against 6.1% here, and its longest run is 41.8 days against 41.4.

With an agent

planaco has no agent integration of its own. The agent writes the YAML and runs the command line.

Pick the shape that fits the uncertainty

Six distributions, set per task.

DistributionShapeUse it forYAML fields
Triangular A three-point estimate. The default. estimator: triangular
min_duration, mode_duration, max_duration
PERT Smoother than triangular, with more weight on the most likely value. estimator: pert
min_duration, mode_duration, max_duration, optional lamb
Uniform Every duration in the range is equally likely. estimator: uniform
min_duration, max_duration
Normal A symmetric bell, cut off below at min_value (0 by default) and optionally above. estimator: normal
mean, std_dev, optional min_value, max_value
LogNormal Right-skewed: most runs land near the estimate and a few overrun badly. estimator: lognormal
mean, std_dev, optional min_value, max_value
Beta A flexible shape set by alpha and beta. estimator: beta
alpha, beta, max_value, optional min_value

Before you install

Can I use it without writing Python?
Yes. Describe the project in a YAML file and run planaco stats project.yaml.
Does it handle dependencies?
Yes. Each task lists what it depends on and waits for all of it. The critical path is found in every run.
Is it stable?
Not yet. Version 0.3.1 is alpha, and the public API may still change between releases.
What does it need?
Python 3.8 or newer, with click, numpy, PyYAML and cairosvg. PNG export also needs the Cairo system library; SVG works without it.
How well is it tested?
100% line coverage today, and CI fails the build below 99%.
What is the licence?
MIT.
